# NotaFácil MEI 🚀

**O emissor de notas fiscais mais simples e rápido para MEIs**

Venda → Pix cai → Nota sai automaticamente. Conecte sua conta em 3 minutos e pare de perder tempo com burocracia fiscal.

## ✨ Funcionalidades

- Login com Supabase Auth
- Configuração completa do MEI (CNPJ, razão social, endereço)
- Emissão de NFS-e Nacional e NF-e/NFC-e
- Histórico completo de notas emitidas
- Dashboard com resumos em tempo real
- Tema claro/escuro

## Como Usar

1. Acesse `/auth` e crie sua conta
2. Preencha seus dados em `/configuracao`
3. Comece a emitir notas em `/emitir`
4. Acompanhe tudo no histórico e dashboard

## Páginas

- `/` → Dashboard com resumo do mês
- `/configuracao` → Seus dados do MEI
- `/emitir` → Emita NFS-e ou NF-e
- `/historico` → Todas as notas emitidas

**Feito para MEIs que querem simplicidade e velocidade.**
